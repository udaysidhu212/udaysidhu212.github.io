Two AI agents I built.

One triages organizational risk, the other watches my own stock portfolio. Same idea both times: let the AI do the judgment, let plain code do the scoring.

01 / RISK TRIAGE AGENT STATUS · LIVE STACK · Claude API, JavaScript

An agent that scores and logs organizational risk.

Modeled on public-sector enterprise risk management practice. Enter a risk in plain language; the tool scores it on a standard 5×5 likelihood × impact matrix, drafts mitigations, suggests an owner, and sets a review cadence — logged to a running register with a heat-matrix view and CSV export.

Try it live →

Requires your own free Anthropic API key.

  • Organizational context (sector, risk appetite, control maturity, relevant history) is entered once and factored into every future assessment — the tool states explicitly when that context changed a score.
  • If context changes later, affected entries are flagged and can be bulk re-scored.
  • Strict split between judgment and math: the model never has the final say on a risk's level — the matrix scoring does.
  • Single self-contained HTML/JavaScript file — runs inside a Claude artifact or standalone in any browser.
02 / PORTFOLIO MONITOR STATUS · LIVE, runs 3×/week STACK · Python, Claude API, GitHub Actions

A daily-digest agent that watches a real stock portfolio.

Reads a list of holdings and researches each one individually for material news — earnings, M&A, regulatory action, analyst moves — plus a broader macro/sector pass, then synthesizes everything into a digest built to read in under three minutes: what needs attention, and what's quiet.

View code →

Sanitized showcase repo — example holdings, same code as the live private agent.

  • Two-model split for cost control: high-volume per-holding research runs on a lighter model, the final synthesis (the one step that needs real judgment) runs on a stronger one.
  • Deliberately doesn't track live prices — there's no reliable free data feed for small-cap Canadian tickers, so rather than guess, it sticks to news and developments only.
  • Runs on a schedule via GitHub Actions, triggered by an external precision scheduler rather than GitHub's own best-effort cron.
  • Delivered by email — no dashboard to check, just a digest when there's something worth reading.
